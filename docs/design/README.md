# Canvas mirrors

Screen designs live in the Claude Design project, not in git:
`ed46e806-ffe6-43c7-9660-01c2cb4b625c` ("Eva App Design Prototype").

Before building a screen, pull its canvas and drop it here so the work is
reproducible:

> Pull `Eva App.dc.html` from the Eva design project into `docs/design/`.

Claude reads it with the `DesignSync` tool (`get_file`). Mirrors are a snapshot —
re-pull rather than editing them, and never treat a stale mirror as the source of
truth. The tokens themselves are transcribed in [../DESIGN.md](../DESIGN.md).
